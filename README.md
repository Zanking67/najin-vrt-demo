# Najin vrt – neuradni demo

Javna predstavitev: https://najin-vrt-demo.vercel.app

Statična stran HTML/CSS/JavaScript. Odprite index.html ali zaženite python3 -m http.server. Fotografije so lokalno v images/; viri in licence so v viri.html. Obrazec ne pošilja in ne shranjuje podatkov. Sezonski koledar je okviren, logotip in fotografije so predstavitveni.

## Gostovanje

Vercel projekt `najin-vrt-demo` je povezan s tem GitHub repozitorijem. Produkcijska veja je `main`. Statične datoteke so v korenu repozitorija; build in install ukaza sta prazna, output directory je `.`. Javna produkcijska stran ne zahteva prijave. Spremembe na `main` se objavljajo prek povezave GitHub–Vercel.
